# mehedishakeel.bd

A single-page cybersecurity knowledge hub and interactive cyberdeck built for ethical hackers, security researchers, and students. Available in both English and Bangla.

## Overview

**mehedishakeel.bd** serves as an open, accessible station for cybersecurity learning, threat research, and ethical hacking tradecraft. Built with a responsive cyberpunk aesthetic, it features real-time search, curated intelligence feeds, and interactive tooling without external runtime dependencies.

## Key Sections

- **Terminal Console**: Interactive command-line interface featuring system MOTD, commands, and cyber navigation.
- **The Ethos**: Core ethical hacking principles emphasizing curiosity, open knowledge, and responsible disclosure.
- **Knowledge Base**: Curated knowledge cards across 10 security domains including Web Security, Network & Infrastructure, Binary Exploitation, Cryptography, OSINT, Cloud Security, and AI/LLM Security.
- **Learning Roadmaps**: Structured step-by-step tracks spanning Foundations, Offensive Core, and Specialization.
- **Masterclass Video Showcase**: Curated flagship video courses by Mehedi Shakeel on YouTube (Ethical Hacking, Web Pentesting, Kali Linux, Bug Bounty, WiFi Pentesting, Metasploit) presented in custom cyberpunk media consoles.
- **Mehedi Shakeel Academy**: Dedicated portal for career-grade masterclasses at `academy.mehedishakeel.com` featuring comprehensive 9-module curriculum, hands-on lab projects, private VIP support community, and verified certification.
- **Arsenal**: Curated directory of 45+ industry-standard security tools organized by discipline.
- **The Dojo**: Direct links to legal practice grounds and labs (PortSwigger, Hack The Box, TryHackMe, picoCTF, OverTheWire, etc.).
- **Lexicon**: Concise definitions for essential security terminology.
- **Curated Feeds**: 40+ security feeds covering threat intelligence, government advisories, zero-days, and security tradecraft.
- **House Rules**: Ethical hacking standards and legal disclaimers.
